    How these numbers were produced

    • Generated by npm run bench:compare (bench/). Every algorithm faces the same seeded traffic in simulated time; no database or network is involved.
    • Legitimate users behave like people: they retype a mistyped password, and retry a refusal after the wait the server asks for - unless it asks for more than two minutes, or refuses them three times, in which case they give up and count as denied.
    • Decision cost is the guard's own time per request, in memory. In production, WEVA's cost is dominated by its database reads and audit writes - see the k6 load-test results for end-to-end latency.
